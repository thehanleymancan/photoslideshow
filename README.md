# photoslideshow
simple slideshow renderer with swipe/numbered jump - indicators up to 5 photos. set container to landscape or portrait. will fully display image

This is a plugin for TwoWay Street (twowaystreet.app) 
Example: 
 https://twowaystreet.app/dirct/62-1145

  works best with a CMS.. pulling data so can loop create slideshows, indicators..captions
